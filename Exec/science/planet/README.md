# planet
Model of Hot Jupiter planet to be used in conjunction with HydroSim(Radiation) code (2-Dimensions)

Actual model parameters defined and calculated in the HotJupiter.cpp file. Outputs to newmodelcpp.hse file for HydroSim to read in.

Inputs to HydroSim are in inputs_2d files

more editable parameters (velocities and vortices) in probin file.
